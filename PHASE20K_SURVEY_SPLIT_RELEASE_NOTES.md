# Phase 20K — Survey Split & Single-Form Control

- Split surveys into Solar Off-Grid Site Survey & Load Assessment and Solar Pumping Site Survey.
- Off-grid survey now uses concise load-summary fields (monthly consumption/bill, connected load, peak load, total/day/night energy, critical load/energy).
- Solar pumping survey captures borehole/water/pump/pipe/tank/solar-area data.
- Prevents creating a second one-time project form; users are redirected to edit the existing form. Daily Site Report remains repeatable by day.
- Daily Site Report remains one record per team + project + report date, which is the recommended structure for approval, audit trail, and progress history.
- Legacy Load Assessment records remain available for historical reference.
